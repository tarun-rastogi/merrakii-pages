Purpose. This document gives Merrakii’s project manager a single reference for what is being built, what each milestone must deliver, and what Merrakii must provide to keep delivery on track. Commercial terms are covered separately in the quotation.

1. Project objective

Merrakii is launching a student-centred web marketplace for Indian learners (Grade 6+, no upper age cap) to discover coaching, test-prep, certification, and diploma programmes from partner vendors; apply; pay fees; and manage enrolments from a personal dashboard. Merrakii staff will maintain catalogue data through an internal operations dashboard.

The launch homepage will present two offerings: overseas admissions (handoff to the existing merrakii.co.in admissions site) and the in-app India marketplace (fully in scope here).

2. Overall scope of work

The web MVP covers the following capability areas:

AreaIn scope
Discovery & marketing Homepage with dual journeys; study pathway hubs; catalogue search and filters (city, fee, mode, category); field → exam → institute browse; institute and exam detail pages
Enrolment Structured apply flow; mobile/email OTP and password auth; Razorpay checkout; payment confirmation; resume incomplete journeys
Learner account Profile, applications, payment status, enrolment history, transactional email on key milestones
Operations Staff dashboard: add/update vendors and programmes; view applications; catalogue publishing; vendor data import template
Platform Responsive Next.js web app, API (Fastify + PostgreSQL), staging and production deployment, UAT support, go-live hypercare, one staff training session

6. Acceptance criteria

UAT must pass these journeys before go-live:

  1. Homepage → overseas site handoff
  2. Search / filters → institute profile → apply → pay → account status
  3. Resume incomplete application
  4. Staff add/edit vendor → visible on public catalogue
  5. Transactional email on test enrolment (staging)

No open Severity-1 defects at release; Severity-2 items require agreed fix or workaround. Cosmetic issues and new features follow change control.
